# PasarTernak.id - VS Code

Starter project untuk rekonstruksi website PasarTernak.id dari Base44.

## Menjalankan
1. Install Node.js LTS.
2. Buka folder ini di VS Code.
3. Buka Terminal.
4. Jalankan:
   npm install
5. Setelah selesai:
   npm run dev
6. Buka alamat localhost yang muncul di terminal.

## Catatan
- Halaman Beranda sudah dibuat sebagai fondasi.
- Route halaman lain sudah disiapkan sebagai placeholder agar navigasi tidak rusak.
- Data produk sementara ada di `src/data/products.js`.
- Gambar produk saat ini menggunakan URL gambar sebagai placeholder; nantinya bisa diganti dengan asset asli.
- Implementasi halaman berikutnya akan mengikuti screenshot Base44 secara bertahap.
