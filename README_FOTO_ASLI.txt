PASARTERNAK.ID - FOTO PRODUK

Versi ini menggunakan endpoint foto dari LoremFlickr dengan kata kunci sesuai kategori dan parameter lock unik per produk/galeri. Ini meminta foto fotografi nyata dari Flickr, bukan ilustrasi SVG yang dibuat untuk versi sebelumnya.

PENTING:
- Koneksi internet diperlukan agar foto dimuat. Foto tidak disimpan di dalam ZIP.
- Endpoint foto acak berdasarkan kata kunci; walaupun setiap produk memakai lock berbeda, layanan tidak menjamin setiap foto cocok tepat dengan ras/jenis produk tertentu. Mohon cek hasilnya setelah website dijalankan.
- Jika ingin 80 foto nyata yang terkurasi dan disimpan lokal, file fotonya perlu diunduh dari sumber yang mengizinkan penggunaan dan dikemas ke public/images/products. Lingkungan pengerjaan ini tidak memiliki akses unduh langsung ke web untuk menyimpan 80 foto lokal.

Jalankan: npm install, lalu npm run dev -- --host 127.0.0.1
